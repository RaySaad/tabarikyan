# Tabarikyan — مستودع موديولات Odoo

هذا المستودع يحتوي موديولات Odoo مخصّصة، كل موديول في مجلده الخاص:

| المجلد | الوصف |
|---|---|
| [`recruitment_workflow/`](recruitment_workflow/) | نظام إدارة مراحل طلبات التوظيف ونقل الكفالة وطلب السيارات وإنشاء العقود. راجع [README الموديول](recruitment_workflow/README.md) للتفاصيل. |

## إضافة موديول جديد

أنشئ مجلداً جديداً باسم الموديول في جذر المستودع، بجانب `recruitment_workflow/` — بنفس بنية موديول Odoo القياسية (`__manifest__.py`, `models/`, `views/`...).
